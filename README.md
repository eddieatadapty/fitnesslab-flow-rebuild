# Layout Growth Audit

**Live → https://eddieatadapty.github.io/fitnesslab-flow-rebuild/**

Five ideas to turn more Layout users into subscribers, each built into a clickable version of Layout's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Make the paywall about the feature they picked | +10–20% CR to purchase |
| 02 | Let them make one collage before the price | +5–15% CR to purchase |
| 03 | Make the yearly plan impossible to miss | +10–15% ARPU |
| 04 | Put 4.6 from 47K ratings right before the price | +5–10% CR to purchase |
| 05 | Give the people who close a second price | +5–10% CR from people who close |

Every price, rating and feature comes from Layout's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Layout. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
